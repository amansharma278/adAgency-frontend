# Quick Start Guide

Welcome to the Digital Advertisement Display Management System! This guide will help you navigate and understand the key features of the application.

## Navigation

The application has a collapsible sidebar on the left with the following main sections:

1. **Dashboard** - Overview of your ad network
2. **Ad Management** - Manage your video advertisements
3. **Devices** - Monitor and control connected displays
4. **Playback Control** - Real-time playback management
5. **Analytics** - Performance metrics and insights
6. **Notifications** - System alerts and updates
7. **Settings** - Configure your preferences

## Key Features

### Dark/Light Mode
- Click the moon/sun icon in the top navigation bar to toggle between dark and light themes
- Your preference is automatically saved

### Notifications
- Click the bell icon to see recent notifications
- The red badge shows the number of unread notifications
- Click "View all notifications" to go to the full notifications page

### Search & Filter
- Most pages include search bars and filter dropdowns
- Search works in real-time as you type
- Filters can be combined with search for precise results

### Pagination
- Tables with many items include pagination controls at the bottom
- Change the number of rows per page using the dropdown
- Navigate pages using the arrow buttons

### Actions
- **Edit** - Modify video or device settings
- **Play/Pause** - Control content playback
- **Delete/Remove** - Remove items (with confirmation)
- **View Details** - See comprehensive information

## Getting Started

1. **Check Dashboard** - Start here to see an overview of your system
2. **Upload an Ad** - Go to Ad Management → Click "Upload New Ad"
3. **Monitor Devices** - Visit the Devices page to see all connected displays
4. **View Analytics** - Check the Analytics page for performance insights
5. **Configure Settings** - Adjust your preferences in the Settings page

## Tips

- Use keyboard shortcuts when available
- Hover over icons to see tooltips
- All changes are confirmed with toast notifications
- Actions that delete data require confirmation
- The system works with mock data - perfect for testing!
